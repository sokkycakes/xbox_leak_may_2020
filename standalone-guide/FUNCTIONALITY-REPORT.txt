XBOX BLADES DASHBOARD - FUNCTIONALITY AND REMAINING WORK

This is a source-backed XUI navigation host, not a complete console OS port.
The supplied scene menus load and native UI navigation is connected. Console
service actions are not all implemented. They must not be mistaken for
working authentication, storage, playback, configuration, or Xbox Live.

IMPLEMENTED
- Exact scene catalog and cross-package navigation for supplied paths.
- Dashboard and Guide submenu stacks, Back, saved focus, and Guide toggling.
- Existing blade timelines; scene visibility enforced after their keyframes.
- Scene-authored default focus, including native list/checkbox/radio/slider controls.
- Original DashScene description and meta-scene properties for submenu panels.
- Xbox Guide skin prefix, frame, animation, clock, legends and music slot.
- Native keyboard/controller mapping; existing fullscreen and mouse support.
- Graphics device reset recovery and explicit scene cleanup.
- Unavailable-operation notices; profile creation is not falsely completed.
- Launch Dashboard.cmd, Blades Dashboard.cmd and Launch Guide.cmd use the new EXE.

CONSOLE FUNCTIONS STILL UNAVAILABLE
1. Identity/profile storage: create/save/recover/sign in to a real Xbox gamer
   profile, passcode validation, persisted profile preferences and signed-in
   account data. The supplied profile/sign-in layouts load, but their console
   handlers and storage provider are not connected. Next on Create Profile
   reports that no profile was created rather than showing Congratulations.
2. Xbox Live: friends, messages, recent players, voice chat/mail, presence,
   account/membership/privacy changes, marketplace, points, purchasing,
   downloads, achievements and server-driven billboards. Their templates
   do not supply the account context, network services or returned data.
3. Storage and content: console FATX devices, profiles/saves/title enumeration,
   copy/move/delete/format, launching Xbox games, game details and actual
   music/picture/video/CD/DVD device and library data. No console storage
   devices are attached, so Storage Devices shows its authored empty state.
4. Playback: media selection/queueing/ripping, decoding/playback, voice output
   and the XMA dashboard sound backend. The Guide music controls are present
   but no media playback service or selected song is connected.
5. Configuration: console display/audio/locale/language/clock/remote/control
   settings, configuration writes, persistent notification/voice/vibration
   preferences, Family Settings policies and installed theme enumeration.
   Native controls can receive input; this does not persist or apply their
   values to an Xbox or to Windows. Hardware setting fields show availability.
6. Network/computers: console adapter and configuration enumeration, connection
   tests, PPPoE/wireless configuration, Windows Media Connect and Media Center
   affiliation. The supplied network settings layouts load; no connection
   is actually configured or tested by the host.
7. System workflow: optical tray operation, power control, and Initial Setup.
   Initial Setup calls the console setup state machine and configuration
   services; the host does not guess a wizard state or jump to its completion
   page. Shutdown does not power off the PC.
8. Application-specific entry/callback data: virtual keyboard/passcode
   completion, dynamic list providers, selection-dependent option panes,
   progress/completion/results and other custom class callbacks. The
   original native UI modules require these providers beyond their layouts.
